# Салют-Огонь — сайт магазина пиротехники в Пятигорске

Одностраничный сайт-витрина: каталог из пяти салютов, акции, доставка,
о компании, контакты и Яндекс.Карта. Без корзины, онлайн-оплаты и форм —
только телефон и WhatsApp.

Откройте `index.html` двойным щелчком. Всё работает без сервера.

Названия и характеристики взяты по фотографиям и тексту на упаковках
приблизительно — замените на точные данные производителя.

Чтобы поменять товар, отредактируйте объект в `PRODUCTS`:

```js
{
  id: "russkiy",                 // уникальный id, латиницей
  name: "Батарея «Русский фейерверк»",
  category: "Батареи",           // должно совпадать с data-filter
  price: 12000,                  // число, без пробелов
  badge: "Хит продаж",           // плашка на карточке
  hue: 38,                       // оттенок фона, если нет фото
  image: "images/7155265999.jpg",// путь к фото
  desc: "Короткое описание",
  meta: "36 залпов · золотой · для двора",
  specs: [["Количество залпов", "36"], ["Калибр", "20 мм"]],
}
```

Категории фильтров: `Батареи`, `Фейерверки`, `Коллекции`, `Подарочные`.

## Как заменить фото

1. Положите новые файлы в `images/`.
2. Укажите путь в поле `image` нужного товара.
3. Рекомендуемый размер — до 1200 px по длинной стороне, JPG/WebP.
   Большие фото замедляют загрузку, особенно на телефоне.

## Яндекс.Карта

Карта встроена в блок «Контакты» через iframe:

```html
<iframe src="https://yandex.ru/map-widget/v1/?text=АДРЕС&z=16" ...></iframe>
```

Адрес в `src` закодирован процентами. Если меняете адрес — проще всего
открыть <https://yandex.ru/map-constructor/> , найти новую точку и взять
готовый код карты оттуда. Ссылка «Открыть в Яндекс.Картах» ведёт на
обычный поиск по адресу.

## Демо-данные, которые нужно заменить перед публикацией

- Название магазина «Салют-Огонь» — если у клиента другое.
- Телефон, email, домен в `canonical` и `og:url`.
- Названия, цены и характеристики товаров.
- Реквизиты: ИНН `000000000000`, ОГРНИП, банковские счета — сейчас вымышленные.
- Тексты акций и сроки их действия.
- Политика конфиденциальности и договор оферты — проверить у юриста.

## Публикация

### Netlify Drop (быстро)

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `salut-demo`.
3. Получите ссылку `https://random-name.netlify.app`.

Без аккаунта сайт живёт ограниченное время и закрыт паролем — только для показа.

### Netlify с аккаунтом

1. Зарегистрируйтесь, создайте сайт.
2. Загрузите папку или подключите Git.
3. HTTPS включится автоматически.

### Свой домен

1. Купить домен у российского регистратора.
2. Добавить домен в настройках сайта на хостинге.
3. Прописать DNS: либо NS хостинга, либо `A` + `CNAME` для `www`.
4. Дождаться обновления DNS (15 минут — 24 часа).
5. Включить HTTPS (Let's Encrypt) и редирект HTTP → HTTPS.

## SEO-чек-лист

- [ ] В `title` и `description` есть город и услуга.
- [ ] Адрес и телефон на сайте совпадают с Яндекс.Картами и Яндекс.Бизнесом.
- [ ] Заполнена JSON-LD разметка `Store` (адрес, гео, часы).
- [ ] `robots.txt` и `sitemap.xml` открываются.
- [ ] Сайт добавлен в Яндекс.Вебмастер и Google Search Console.
- [ ] В Вебмастере указан регион: «Представление в поиске» → «Региональность».
- [ ] Создана карточка в Яндекс.Бизнесе со ссылкой на сайт.
- [ ] Проверено на телефоне: меню, звонок, WhatsApp, карта.
- [ ] HTTPS работает, сертификат не просрочен.

## Проверка перед показом

- Открыть на телефоне и компьютере.
- Нажать «Позвонить» и «WhatsApp».
- Отфильтровать каталог по категориям.
- Открыть «Подробнее» у каждого товара, проверить характеристики.
- Пройти по ссылкам в подвале: акции, реквизиты, оферта, политика.
- Проверить карту и кнопку «Открыть в Яндекс.Картах».
- Посмотреть консоль браузера (F12 → Console) — ошибок быть не должно.
